Target: `D:\Anything\kooky-win`. Independent Windows implementation; reference checkout is read-only.

Runtime: .NET 10 Windows host + WebView2, native ConPTY, xterm.js. A separate per-user broker owns PTYs so closing/restarting the UI preserves running processes. Full broker/OS restart restores layout and offers exact native session resume; arbitrary shell process memory cannot survive reboot.

libghostty assessment: upstream 1.4 release notes confirm Windows support for the library. It requires a separate native renderer/Zig integration, absent from Kooky's macOS xcframework. xterm.js is the initial mature rendering implementation; ConPTY remains the real terminal backend.

Delivery ledger (all pending until real evidence): desktop launch; multiple projects; official Claude/Codex TUI; five concurrent PTYs; background tab survival; draggable/splittable panes; tray/background survival; UI reattach and native-session recovery; accurate Git/activity; custom environment; file tree/search; notifications/hotkey/HUD; corruption recovery; resource measurements by process group; installable package; update mechanism and migration.

Boundaries: no changes outside this project except normal local app data and explicitly run CLI session data. Never modify user Claude/Codex configuration, overwrite another project, infer permission prompts from terminal text, invent agent states, or bypass CLI permission defaults.

IPC: JSON lines over CurrentUserOnly named pipes. Request `{id,type,payload}` response `{id,ok,result,error}`. WebView2 uses same envelope through postMessage. Event `{type,payload}`. Output strings are decoded UTF-8 with monotonic sequence. UI must buffer output during replay and ignore sequence already replayed.

UI commands: bootstrap -> {state,agents,sessions,appVersion,homePath}; state.save -> payload opaque state object; agents.save -> {agents}; session.create -> SessionRequest; session.list -> SessionInfo[]; session.input/resize/close/rename/replay/resume -> {sessionId,data?,cols?,rows?,title?}; workspace.inspect -> {path}; workspace.files -> {root,path}; agents.history -> {agentId,cwd}; dialog.folder -> path|null; clipboard.read/write -> string/{text}; window.hide/monitor/new/minimize/maximize; path.open -> {path}; performance -> measurements.
